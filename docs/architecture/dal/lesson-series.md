# `lesson-series.ts`

`createLessonSeries(params, client?)` — same param/return shape as `createLessonWithParticipants`, and like it passes no `p_instructor_cut` (#1154 — see [`lesson-participants.md`](lesson-participants.md)); calls `create_lesson_series_with_participants` to atomically create the `lesson_series` template row and its first `lessons` row (tagged with `series_id`) in one transaction; used by `submitLesson` when the "Recurring (weekly)" checkbox is checked, in place of `createLessonWithParticipants`.
`getSeriesById(seriesId, barnId, client?)` — barn-scoped lookup, returns `LessonSeries | null`; used by the lesson edit page and `stopLessonSeriesAction`.
`stopLessonSeries(seriesId, barnId, client?)` — direct table update setting `is_active=false`, scoped by id+barn_id, relying on `lesson_series`' own RLS (manager: any; trainer: own) for authorization; used by `stopLessonSeriesAction` in `src/app/actions/lessons.ts` and by the nightly `scripts/generate-recurring-lessons.ts` when a series' rider is no longer an active member.
`generateNextLessonForSeries(seriesId, barnId, lessonAt, client?)` — thin wrapper calling the `generate_lesson_for_series` RPC (unchanged signature — the RPC reads `instructor_cut` from the stored series template); used by `scripts/generate-recurring-lessons.ts`
