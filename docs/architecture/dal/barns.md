# `barns.ts`

Barn lookups; `updateBarnDefaultBoardFee(barnId, defaultBoardFee, client?)` — manager-only write, backed by an RLS policy scoped by `auth_is_barn_manager(id)`; `setInstructorCut(barnId, value, client?)` — calls `set_instructor_cut` RPC, which now writes `barns.default_instructor_cut` (#776; function/wrapper names unchanged); `updateExhaustionThresholds(barnId, { moderate, high }, client?)` — direct table update of `exhaustion_threshold_moderate`/`exhaustion_threshold_high`, backed by the same `manager_update_barns` RLS policy as `updateBarnDefaultBoardFee`; `updateBarnTimezone(barnId, timezone, client?)`
(#955) — direct table update of `timezone`, same RLS policy, mirroring `updateBarnDefaultBoardFee`'s shape exactly; `updateScheduleBufferMinutes(barnId, minutes, client?)`
(#1017) — direct table update of `schedule_buffer_minutes`, same shape/RLS again; used by the Manage Barn settings page (`/barn/[slug]/settings`); `countDemoBarns(client)`/`getOldestDemoBarn(client)`/`deleteBarn(barnId, client)`/`createDemoBarn(slug, client)` (#505) — `is_demo=true` count/oldest-by-`created_at` lookup, a plain-id delete, and an `is_demo: true` insert, all requiring a service-role `client` (no request-scoped default — a regular authenticated user has no RLS path to any of these), used by `/demo`'s `createOrResumeDemoBarn` action for the `DEMO_BARN_CAP` reap check and new-barn creation, and by `/api/cron/reset-demo` (#506) for its daily age/cap reap loop (daily, not hourly, because Vercel's Hobby plan allows a cron at most one run per day — #1438) (`createDemoBarn` not used there — the cron route only reaps, never creates)
